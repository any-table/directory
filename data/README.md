# Public listings

`tables.json` is a nightly copy of every public listing in the directory at [tables.anytable.org](https://tables.anytable.org), made by `.github/workflows/copy-listings.yml`. It is dedicated to the public domain under CC0.

It holds what each listing shows publicly and nothing else: no email addresses or other contact details. It also records every removal a custodian has made, with its reason.

If the website is ever lost or captured, this file is enough to rebuild the directory. Its commit history shows every listing that has ever been public, which is why nothing private is ever put in it.
